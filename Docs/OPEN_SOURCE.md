# Sharing and distributing VisionStream

The original VisionStream code is licensed under MIT at the owner's request. `LICENSE` grants reuse, modification and redistribution, including commercial distribution, subject to preserving its notice. The application also bundles that licence. Existing third-party licences remain separate: MIT does not relicense Python, certifi, the Apache stereo material or the LGPL remux library. See THIRD_PARTY_NOTICES.md, Licenses and Docs/MEDIA_RUNTIME.md.

A public GitHub source repository can be shared without buying Apple Developer Program membership. Xcode/simulator builds remain free. Individuals can use their own Apple Account/Personal Team for device testing, subject to Apple's provisioning limits. Anyone publishing their own App Store/TestFlight build needs their own paid membership, registered identifier, signing and submission. Providing source or an unsigned archive is not the same as a universally installable signed app.

Keep private credentials, Config/Local.xcconfig, publication/signing owner files, DerivedData, LocalMedia, generated result bundles and private reports out of Git. Use `python3 Scripts/package_public_source.py` to prepare `VisionStream-public-source.zip` for public sharing. It excludes TestResults, LocalMedia, generated fixture media, owner/signing settings and user workspace state, and verifies ZIP bytes. The separate full development source ZIP includes local test evidence and is intended for private development handover. Review documentation and any modifications before publishing. The .gitignore excludes generated fixture media; recreate original CC0 fixtures before running full streaming tests. The public source repository is https://github.com/hsingh134/VisionStream. No App Store or TestFlight release is provided.

Each distributor should set their own name, public support/privacy URLs, team and bundle ID using the templates in Config and the instructions in Submission/README.md. Keep the generic personal scheme for development, and use the separate AppStore configuration for distribution. Do not replace another person's existing bundle ID unless intentionally installing a separate app; its saved data will not automatically migrate between identities.

Third-party media and website rights are separate from the app code licence. Download authorization, export classification for bundled OpenSSL, LGPL source/relink delivery, real public contact pages, Apple validation and physical Vision Pro acceptance still apply to whoever distributes a build. The MIT licence does not make those decisions or guarantee App Store approval. Do not submit a development privacy page with missing publisher details as a completed public policy.

The local archive/preflight scripts neither enroll accounts nor purchase membership, publish websites, create a repository or upload a build. Review and publish source separately when ready.
