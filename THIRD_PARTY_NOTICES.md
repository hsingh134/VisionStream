The on-device stream finder embeds the Python 3.14.9 visionOS runtime from
[BeeWare Python Apple Support, package 3.14-b13](https://github.com/beeware/Python-Apple-support/releases/tag/3.14-b13),
the pure Python [yt-dlp 2026.10.21 package](https://github.com/yt-dlp/yt-dlp) (Unlicense),
and [certifi 2026.10.23](https://github.com/certifi/python-certifi) (MPL 2.0).
Its code is bundled with the app; the app does not install or update executable code at runtime.
No PyInstaller-bundled yt-dlp executable or JavaScript runtime is included.
Desktop helper processes are disabled in the visionOS Python adapter.

Python Apple Support includes platform patches to CPython. VisionStream does not
modify that runtime's C source or binaries. We modify one line of its MIT-licensed
build helper to quote a generated filename correctly when the workspace path
contains spaces. Our packaging script performs this reproducible change after
verifying the published archive's SHA-256 checksum.

The runtime's published version inventory lists BZip2 1.0.8, libFFI 3.4.7,
mpdecimal 4.0.0, OpenSSL 3.5.9, XZ 5.6.4 and Zstandard 1.5.7.
The Python, yt-dlp, certifi, build-helper and dependency licence texts are included
in `Licenses/EmbeddedRuntime.txt` and the app bundle. The pinned source URLs and
archive checksums are in `Vendor/dependencies.lock.json`.

licensed under **LGPL 2.1 or later**. This is a separate dynamically linked
framework. GPL and nonfree components, network protocols, encoders and executable
programs are disabled. It remuxes local clear H.264/HEVC + AAC MPEG-TS into MP4
without re-encoding. FFmpeg itself is unmodified; our C adapter and reproducible
build script are supplied in `Vendor/MediaSource` and `Scripts/build_media_runtime.py`.
The complete corresponding source archive, source checksum and configuration
manifest are in `Vendor/FFmpeg`; the licence is in `Licenses/FFmpeg-LGPL-2.1.txt`
and the app bundle. See `Docs/MEDIA_RUNTIME.md` for rebuilding and replacing the
framework. You may modify and replace the library and reverse engineer this
application as needed to debug those modifications. No additional restriction in
this project overrides those LGPL rights.
